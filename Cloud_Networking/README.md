## 📌 Visión General del Módulo

Arquitectura de red empresarial para entornos Multi-Cloud e híbridos. Comparativa profunda entre arquitecturas VPC/VNet en AWS, Azure y Google Cloud (GCP), puertas de enlace de tránsito (Transit Gateway, Virtual WAN), enlaces dedicados Direct Connect y ExpressRoute, y despliegue de Routers Virtuales (Cisco Catalyst 8000v) con BGP dinámico.
