## 📌 Acerca de esta Guía

Conmutadores legados 3Com Switch 4500, 5500 y equipos H3C basados en el sistema operativo empresarial Comware.

Cada archivo aborda un nivel de complejidad progresivo, explicado paso a paso con sintaxis probada en entornos de producción y laboratorios reales.
