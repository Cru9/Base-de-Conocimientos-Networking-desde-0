## 📌 Visión General del Módulo

Colección de herramientas nativas en PowerShell (.ps1) y batch (.cmd) diseñadas para ingenieros de redes y administradores de sistemas en entornos Windows. Permite realizar auditorías de Wi-Fi, monitoreo continuo de latencia (SuperPing con marcas de tiempo en milisegundos), descubrimiento de MTU de ruta (PMTU con bandera DF), escaneo rápido de puertos TCP y generación de reportes de salud de red.
