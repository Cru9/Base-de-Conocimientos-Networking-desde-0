# 🧪 Entornos de Laboratorio y Simulación de Redes

Para poner en práctica los **200 laboratorios** de la carpeta [`Ejemplos/`](https://github.com/Cru9/Manual-Maestro-Redes-Ciberseguridad/tree/main/Ejemplos) y las guías técnicas de este repositorio, existen tres plataformas de emulación y simulación recomendadas en la industria:

---

## ⚖️ Comparativa de Simuladores y Emuladores

| Criterio | Cisco Packet Tracer | GNS3 | EVE-NG (Community / Pro) |
| :--- | :--- | :--- | :--- |
| **Tipo de Software** | Simulador de software (ligero) | Emulador de hardware real | Emulador de hardware bare-metal/web |
| **Consumo de Recursos** | Mínimo (funciona en cualquier PC) | Medio a Alto (según cantidad de nodos) | Medio a Alto (requiere máquina virtual o servidor) |
| **Interfaz de Usuario** | Gráfica de escritorio | Gráfica de escritorio (con VM auxiliar) | 100% Web HTML5 (acceso vía navegador) |
| **Soporte Multi-Vendor** | Solo Cisco | Excelente (Cisco, Huawei, Fortinet, Linux) | Excelente (Cisco, Huawei, Aruba, Palo Alto, MikroTik) |
| **Fidelidad de CLI** | 80% (comandos simulados) | 100% (imágenes de sistemas operativos reales) | 100% (imágenes QCOW2 oficiales de producción) |
| **Nivel Recomendado** | CCNA / Network+ | CCNP / Seguridad / PyMEs | CCNP / CCIE / Datacenter / Multi-Cloud |

---

## 1. 🟢 Cisco Packet Tracer (Para Nivel Asociado / CCNA)

Ideal para comenzar sin necesidad de hardware potente.

### Ventajas:
- Gratuito proporcionado por Cisco Networking Academy.
- Modo simulación paso a paso con inspección visual de tramas y paquetes (PDU inspection).
- Excelente para VLANs, Inter-VLAN routing, STP básico, OSPF Single-Area, ACLs y DHCP.

### Limitaciones:
- No soporta comandos avanzados de BGP, MPLS L3VPN o VXLAN.
- No soporta equipos de otros fabricantes (Huawei, Aruba, Fortinet).

---

## 2. 🟡 GNS3 (Graphical Network Simulator-3)

Plataforma clásica de emulación basada en cliente de escritorio y servidor GNS3 VM.

### Imágenes Recomendadas:
- **Routers Cisco:** Cisco c7200 con IOS 15.2 (vía Dynamips) o Cisco IOU/IOL (Cisco IOS on Linux L2/L3).
- **Sistemas Abiertos:** MikroTik Cloud Hosted Router (CHR) y VyOS.

---

## 3. 🟣 EVE-NG (Emulated Virtual Environment - Next Generation)

La plataforma estándar utilizada por academias y empresas para arquitecturas complejas y multi-fabricante.

### Despliegue Recomendado:
1. Descargar la imagen ISO u OVA de **EVE-NG Community**.
2. Montarla en **VMware Workstation Pro** o un servidor dedicado con **Proxmox VE / ESXi**.
3. Asignar mínimo:
   - 4 a 8 vCPUs (con virtualización anidada Intel VT-x/AMD-V activada).
   - 16 GB a 32 GB de memoria RAM.
   - 60 GB de almacenamiento SSD.

### Catálogo de Nodos para los Laboratorios del Repositorio:
* **Cisco Switching / Routing:** `vios-adventerprisek9` y `viosl2-adventerprisek9`.
* **Cisco Datacenter:** `nxosv9k` (Nexus 9000v para VXLAN/EVPN).
* **Huawei:** `huaweiar` y `huaweiusg6000v`.
* **Aruba:** `arubacx` (ArubaOS-CX switch virtual).
* **Firewalls:** `fortinet` (FortiGate VM) y `paloalto` (PAN-OS VM).
* **Linux / DDI:** Ubuntu Server con NetBox, ISC-DHCP y BIND9.
