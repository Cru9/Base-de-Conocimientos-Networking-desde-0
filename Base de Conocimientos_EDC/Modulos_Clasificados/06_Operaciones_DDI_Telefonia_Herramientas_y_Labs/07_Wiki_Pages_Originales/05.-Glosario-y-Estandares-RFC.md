# 📖 Glosario Técnico y Estándares RFC / IEEE

Guía de referencia rápida de acrónimos clave, números de puerto estándar y RFCs oficiales abordados en el repositorio.

---

## 🔤 Glosario de Acrónimos Fundamentales

| Acrónimo | Significado en Inglés | Definición Técnica en Español |
| :--- | :--- | :--- |
| **AAA** | Authentication, Authorization, Accounting | Marco de seguridad que gestiona quién eres, qué permisos tienes y qué hiciste. |
| **ACL** | Access Control List | Lista secuencial de reglas para permitir o denegar tráfico de red o accesos. |
| **BFD** | Bidirectional Forwarding Detection | Protocolo ultrarrápido para detectar fallas en enlaces físicos en submilisegundos. |
| **BGP** | Border Gateway Protocol | Protocolo de vector de rutas estándar que hace funcionar el enrutamiento en Internet. |
| **CAM** | Content Addressable Memory | Memoria de alta velocidad en switches que almacena la tabla de direcciones MAC. |
| **DAI** | Dynamic ARP Inspection | Función de seguridad en conmutadores que evita el envenenamiento ARP (ARP Spoofing). |
| **DiffServ** | Differentiated Services | Arquitectura de Calidad de Servicio (QoS) basada en clases y marcado de paquetes IP. |
| **DMVPN** | Dynamic Multipoint VPN | Solución para crear túneles IPsec dinámicos entre múltiples sucursales sin configuración manual punto a punto. |
| **DSCP** | Differentiated Services Code Point | Campo de 6 bits en la cabecera IP para clasificar prioridades de tráfico (ej. DSCP 46 EF para Voz). |
| **EAP** | Extensible Authentication Protocol | Marco de autenticación extensible utilizado en redes 802.1X (EAP-TLS, PEAP). |
| **EVPN** | Ethernet Virtual Private Network | Plano de control BGP utilizado para transportar direcciones MAC e IP sobre túneles VXLAN en Datacenters. |
| **FHRP** | First Hop Redundancy Protocol | Protocolos de redundancia de puerta de enlace por defecto (HSRP, VRRP, GLBP). |
| **LACP** | Link Aggregation Control Protocol | Estándar IEEE 802.3ad para agrupar múltiples enlaces físicos en un canal lógico. |
| **MAB** | MAC Authentication Bypass | Autenticación basada en dirección MAC para dispositivos que no soportan 802.1X (impresoras, cámaras). |
| **MPLS** | Multi-Protocol Label Switching | Tecnología de transporte de alta velocidad basada en etiquetas en proveedores de telecomunicaciones. |
| **MTU** | Maximum Transmission Unit | Tamaño máximo en bytes de una trama o paquete que puede transmitirse sin fragmentar (1500 bytes estándar). |
| **NAT** | Network Address Translation | Traducción de direcciones IP privadas (RFC 1918) a direcciones IP públicas de Internet. |
| **NGFW** | Next-Generation Firewall | Cortafuegos con inspección profunda de aplicaciones (Capa 7), IPS, antivirus y descifrado SSL. |
| **OSPF** | Open Shortest Path First | Protocolo de enrutamiento interior de estado de enlace basado en el algoritmo de Dijkstra. |
| **OT** | Operational Technology | Redes y hardware dedicados a la automatización física e industrial (PLCs, SCADA, sensores). |
| **PoE** | Power over Ethernet | Suministro de energía eléctrica a través del mismo cable de red de cobre (802.3af/at/bt). |
| **QoS** | Quality of Service | Conjunto de técnicas para garantizar ancho de banda y baja latencia al tráfico crítico. |
| **RSTP** | Rapid Spanning Tree Protocol | Estándar IEEE 802.1w para prevenir bucles de conmutación con convergencia rápida en segundos. |
| **SVI** | Switch Virtual Interface | Interfaz lógica en un switch multicapa asociada a una VLAN para enrutamiento y administración. |
| **TACACS+** | Terminal Access Controller Access-Control System Plus | Protocolo propietario de Cisco (ahora RFC 8907) para administración segura de consolas de red. |
| **VLAN** | Virtual Local Area Network | Segmentación lógica de una red física en múltiples dominios de difusión independientes. |
| **VXLAN** | Virtual Extensible LAN | Protocolo de encapsulamiento que permite crear redes de Capa 2 sobre una infraestructura de Capa 3. |

## 📜 Principales Estándares IETF (RFC) e IEEE

* **IEEE 802.1Q:** Etiquetado de tramas VLAN en enlaces troncales.
* **IEEE 802.1X:** Control de acceso a puertos de red basado en identidad.
* **IEEE 802.3ad:** Agregación de enlaces dinámica (LACP).
* **RFC 791:** Protocolo de Internet (IPv4).
* **RFC 793:** Protocolo de Control de Transmisión (TCP).
* **RFC 1918:** Direccionamiento IP privado para redes corporativas.
* **RFC 2328:** Protocolo de Enrutamiento OSPF Versión 2.
* **RFC 4271:** Protocolo de Puerta de Enlace de Borde 4 (BGP-4).
* **RFC 4594:** Arquitectura de Clases DiffServ para Calidad de Servicio (QoS).
* **RFC 7348:** Especificación de Conmutación Virtual Extensible (VXLAN).
* **RFC 8907:** Protocolo de Seguridad TACACS+.
