## 📌 Visión General del Módulo

Ingeniería completa de Comunicaciones Unificadas y Telefonía IP corporativa. Desde protocolos base SIP, SDP, RTP y códecs de audio (G.711, G.729, Opus) hasta la configuración integral de hardware y software en plataformas propietarias como Avaya IP Office 500v2 (Manager, SCN multi-sitio, aprovisionamiento DHCP) y sistemas abiertos como FreePBX, Issabel y Asterisk.
