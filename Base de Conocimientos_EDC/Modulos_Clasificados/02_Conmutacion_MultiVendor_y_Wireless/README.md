## 📂 Submódulos Incluidos

1. **[`01_Switching_CLI_MultiVendor/`](./01_Switching_CLI_MultiVendor/)**  
   - Conmutación homologada para 6 fabricantes líderes:
     - `Cisco/`: Catalyst IOS / IOS-XE
     - `Huawei/`: CloudEngine / Quidway VRP
     - `Aruba/`: ArubaOS-CX
     - `HP/`: ProCurve / Provision AOS-S
     - `3Com/`: 3Com / H3C Comware OS
     - `TP-Link/`: JetStream L2/L3 Managed
   - *Mejoras aplicadas:* Se corrigió el typo de archivo y contenido `05_redudancia_y_agregacion_...` a **`05_redundancia_y_agregacion_...`** en todas las marcas.

2. **[`02_Troubleshooting_Switches/`](./02_Troubleshooting_Switches/)**  
   - Diagnóstico metódico de puertos `err-disabled`, bucles de Spanning Tree, desajustes de VLAN nativa, fallas LACP y problemas de SVI.
   - Gotchas y comandos de visualización rápida por marca.

3. **[`03_Wireless_Enterprise/`](./03_Wireless_Enterprise/)**  
   - Arquitectura centralizada de controladores WLC y túneles CAPWAP.
   - Seguridad Wi-Fi corporativa: WPA3-SAE, WPA3-Enterprise y 802.1X.
   - Planificación de RF, bandas de 2.4 GHz, 5 GHz y 6 GHz, y roaming asistido (802.11k/v/r).
