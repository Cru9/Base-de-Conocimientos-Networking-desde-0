## 📌 Visión General del Módulo

Manual avanzado para el análisis de paquetes a nivel de bit y resolución de problemas de rendimiento con Wireshark. Detalla los filtros de visualización indispensables para ingenieros de red, análisis profundo de anomalías en la pila TCP (retransmisiones, Dup ACKs, Zero Window, RST), auditoría de flujos multimedia VoIP/RTP y casos prácticos de investigación forense ante incidentes de ciberseguridad.
