# 🛠️ Suite de Herramientas y Scripts para Windows

La carpeta [`Tools/`](https://github.com/Cru9/Manual-Maestro-Redes-Ciberseguridad/tree/main/Tools) del repositorio contiene un conjunto de utilidades nativas desarrolladas en **PowerShell (.ps1)** y scripts por lotes (**CMD**) para diagnóstico rápido, auditoría de redes inalámbricas y pruebas de rendimiento sin instalar software de terceros.

---

## 🚀 Cómo Iniciar la Suite

### Opción 1: Menú Interactivo (La Forma Más Rápida)
Simplemente haz doble clic sobre el archivo:
```text
Tools\Menu_Principal.cmd
```
Este iniciador abre una consola con menú interactivo numerado y salta automáticamente las restricciones de política de ejecución de PowerShell.

### Opción 2: Ejecución Directa en PowerShell
Si deseas invocar un script puntual desde la consola:
```powershell
powershell -ExecutionPolicy Bypass -File .\Tools\SuperPing_Continuo.ps1
```

## 🧰 Catálogo de Utilidades

### 1. `SuperPing_Continuo.ps1`
* **Propósito:** Monitor avanzado de latencia y pérdida de paquetes.
* **Características:**
  - Marcas de tiempo (*timestamp*) en milisegundos por cada ping.
  - Alertas visuales en color:
    - 🟢 Verde: Latencia normal (<30 ms).
    - 🟡 Amarillo: Latencia media (30 - 80 ms).
    - 🔴 Rojo: Latencia crítica (>80 ms o tiempo agotado).
  - Alerta sonora (*Beep*) automática ante paquetes caídos.
  - Registro de resultados en archivo CSV para auditoría con clientes.

### 2. `Descubridor_MTU_Path.ps1`
* **Propósito:** Detección del MTU de ruta (Path MTU Discovery) mediante pings con bandera **DF (Don't Fragment)**.
* **Aplicación:** Esencial para dimensionar el MTU y TCP MSS óptimo en túneles **IPsec**, **WireGuard**, **GRE** y evitar fragmentación oculta en proveedores de Internet.

### 3. `Wifi_Analyzer_Audit.ps1`
* **Propósito:** Auditoría y análisis de espectro inalámbrico en tiempo real.
* **Información que extrae:**
  - Todos los SSIDs visibles y sus direcciones BSSID (MAC física del AP).
  - Canales utilizados (2.4 GHz y 5 GHz) para detectar solapamiento de frecuencias.
  - Nivel de señal RSSI en porcentaje (%) y dBm.
  - Tipo de autenticación y cifrado (WPA2-PSK, WPA3-SAE, 802.1X).

### 4. `Reporte_Salud_Red.ps1`
* **Propósito:** Auditoría rápida del host local.
* **Salida:** Genera un reporte formateado en HTML con tablas de interfaces, direcciones IP, gateways activos, DNS primario/secundario y sockets TCP/UDP escuchando en el sistema.

### 5. `Port_Scanner_Rapido.ps1`
* **Propósito:** Escaneo multihilo de puertos TCP (HTTP, HTTPS, SSH, RDP, DNS, Telnet, SMB) para comprobar si un firewall o host remoto está respondiendo en el servicio requerido.
