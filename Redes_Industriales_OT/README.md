## 📌 Visión General del Módulo

Arquitectura y convergencia segura IT/OT para entornos de manufactura, energía, petróleo y automatización industrial. Detalla la segmentación por niveles del Modelo Purdue (Nivel 0 Procesos a Nivel 5 Corporativo), protocolos industriales SCADA/PLC (Modbus TCP, DNP3, OPC UA, PROFINET, CIP), el estándar internacional de ciberseguridad ISA/IEC 62443 y hardening de switches para riel DIN.
